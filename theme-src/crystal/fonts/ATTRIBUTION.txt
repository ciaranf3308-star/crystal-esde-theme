Fonts bundled with the Crystal ES-DE theme
==========================================

DejaVuSans-Bold.ttf / DejaVuSans.ttf
  "DejaVu Sans" by the DejaVu project (derived from Bitstream Vera).
  Source: system DejaVu fonts (https://dejavu-fonts.github.io/)
  License: permissive free license (see DejaVu LICENSE)
  Used for the game-library display type (Bold) and body copy (Regular).
  v17.6.0: PermanentMarker-Regular.ttf was removed; all gamelist
  typography is DejaVu Sans (Bold for display/anchors, Regular for
  body/micro) for a disciplined premium-editorial shell.

Inter-Medium.ttf
  "Inter" by Rasmus Andersson.
  Source: https://github.com/google/fonts (ofl/inter), wght=500
  static instance generated from the variable font via fonttools.
  License: SIL Open Font License 1.1
  Used for left-column body copy and metadata values (libDesc,
  libPlayers, libDev): one weight step up from DejaVu Sans Regular
  for on-device legibility, at a slightly smaller size.
